# SpendSense: Software Architecture Specification (SAS)

## 1. Introduction
The objective of this Software Architecture Specification is to describe how SpendSense is structured and how various components of the system interact with each other. Also, the specification will describe how the chosen architecture fulfills the functional and non-functional requirements that are defined in the Software Requirements Specification. This document will describe the current version of SpendSense system and will include the patterns of architecture, technologies, API contracts, data handling and deployment of the system. The SAS needs to be referred along with the Software Requirements Specification because it includes the requirements, use cases, domain model and quality requirements of the system.
